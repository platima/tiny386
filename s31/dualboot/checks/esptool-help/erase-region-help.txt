esptool v5.4.0
                                                                                
 Usage: esptool erase-region [OPTIONS] ADDRESS SIZE                             
                                                                                
 Erase a region of the SPI flash memory.

│ --spi-connection  -sc  SPI-CONNECTION  Override default SPI flash memory     │

│                                        numbers to use for SPI flash          │
│                                        (CLK,Q,D,HD,CS). Not supported with   │
│                                        ESP8266.                              │
╰──────────────────────────────────────────────────────────────────────────────╯
