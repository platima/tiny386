The three scripts' main flow, run on this PC (cmd.exe) with a stub esptool that never touches a
port.  make_flow.py (bat-harness-make-flow.py here) copies each .bat up to and including the Y
check verbatim, so the file checks and the board read run as written; the write calls after the
check are cut out and replaced by 'echo WOULD WRITE'.  The stub's read-mac prints a made-up MAC;
its read-flash copies a chosen table: linux is be5b725's partition-table.bin (equal to its
flash.bin at 0x8000), dual and own are images\korvo1-dualboot and images\korvo1-standalone's
tables, other is Linux's with one byte changed.  image-info prints the v3.1 Korvo-1 image's real
esptool output (or the same marked invalid).  The scripts' temporary files went to the harness's
own folder (TEMP set there), shown below as <harness folder>.  23 cases, 2026-10-21.
